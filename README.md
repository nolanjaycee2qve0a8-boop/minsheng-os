# 民生OS（Minsheng OS）

民生OS 是一个 evidence-first 的房地产、居民、银行与财政研究工作台。它强调可追溯证据、资格边界与研究纪律，而非自动生成投资建议、全国损失结论或因果断言。

## 研究边界

- `REAL`：经来源、期间、口径和人工审查验证的观测；
- `DERIVED`：带公式、输入和修订失效逻辑的派生结果；
- `SCENARIO`：隔离的假设运行，绝不写入 `REAL`；
- `UNKNOWN`：未知即保留未知，绝不以零补齐。

研究框架覆盖六个相互隔离的部门视角：居民、房地产开发、银行、土地财政与地方政府、宏观金融、证据与制度研究。银行样本不外推为全国结论；相关、回归和情景均不是因果证明。

## 公共 clone 快速开始

需要 Node.js 22+ 与 Python 3.11+（项目当前也在更新版本运行）。公共默认验证无需原始 PDF、HTML、银行年报或网络访问：

```text
node tools/run_public_ci.js
```

该命令输出 `PASS`、`FAIL` 与 `NOT_RUN` 分类。真实浏览器、local-only 原件校验和 LIVE acquisition 不属于公共 CI，且不会伪装为通过。

## 数据与使用限制

本项目不是投资建议、正式预测或全国损失估计工具。公开仓库不分发第三方原始资料；fixture 仅用于测试，不能成为 `REAL` 或 LIVE 证据。详见 [第三方数据边界](THIRD_PARTY_DATA_BOUNDARY.md) 与 [公共复现说明](PUBLIC_REPRODUCIBILITY.md)。

当前未附带开源许可证；除适用法律另有规定外，不授予额外使用或再分发许可。
